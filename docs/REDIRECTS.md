# Redirect stubs under docs/dev, docs/v1.14, docs/v1.16, docs/v1.18

`zhou-lab.github.io/sesame/` was the R package's documentation site before it
moved to `zhou-lab.github.io/sesame-docs/`. When this repository became
`zhou-lab/sesame` (2026-09-23), its project site took over the whole
`/sesame/` path, shadowing the redirect stubs the org site had left behind
for the old vignette links. These 28 files are those stubs, byte for byte,
so `zhou-lab.github.io/sesame/v1.18/sesame.html` and its siblings still
forward to `sesame-docs`. Do not remove them: paper-era links point here.
